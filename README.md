# Trust Center Agent Prototype

A static build of the Trust Center **Ask AI Agent** chat prototype, from the comply-ui sandbox (branch `claude/trust-center-agent-prototype`, commit 1d8d8db94). The conversations are scripted mock data.

Once GitHub Pages is on, these pages open from the site root:

| Page | Hash |
|---|---|
| Prototype (full Trust Center, with the inspector) | `#/trust-center/preview` (the default) |
| Modules: Production vs Final | `#/trust-center/modules` |
| Every module state | `#/trust-center/modules/states` |
| Chat comparison | `#/trust-center/compare` |
| Decision log and every lab option | `#/trust-center/labs` |

Design reference PR: https://github.com/conveyor/comply-ui/pull/3994
